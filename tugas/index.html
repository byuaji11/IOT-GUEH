IoT & Robotics Project

Smart RC Car Controller

Mobil Remote Control berbasis Arduino Uno yang dikendalikan secara real-time via aplikasi Smartphone.

🤖 Tentang Proyek

Proyek ini bertujuan untuk memodifikasi mobil RC konvensional menjadi perangkat pintar berbasis internet/nirkabel. Menggunakan otak utama Arduino Uno, sistem menerapkan kontrol motor, sensor, dan komunikasi nirkabel untuk menciptakan pengalaman berkendara yang lebih responsif dan otomatis.

⚡ Fitur Utama

📱 HP Kendali Jarak Jauh

Interface tombol atau giroskop di smartphone memudahkan manuver belok dan kecepatan.

🌐 Koneksi IoT Instant

Menggunakan modul nirkabel hemat daya dengan latensi rendah untuk respon pergerakan real-time.

🔋 Manajemen Daya L298N

Sistem driver motor DC ganda sanggup menahan lonjakan tegangan baterai secara aman.
