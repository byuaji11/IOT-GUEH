🤖 Tentang Proyek

Proyek ini bertujuan untuk memodifikasi mobil RC konvensional menjadi perangkat pintar berbasis internet/nirkabel. Menggunakan otak utama Arduino Uno, sistem ini dirancang untuk menerima perintah dari smartphone dan mengendalikan gerakan mobil dengan respons cepat, presisi, dan stabilitas yang lebih tinggi. Selain berfungsi sebagai alat demonstrasi teknologi IoT, proyek ini juga relevan sebagai media pembelajaran mengenai komunikasi serial, mikrokontroler, pengendalian motor, hingga integrasi perangkat keras dan perangkat lunak secara nyata.

⚡ Fitur Utama

Beberapa keunggulan utama dari sistem kendaraan pintar berbasis Arduino ini.

📱

Kendali Smartphone

Interface tombol atau giroskop di smartphone memudahkan navigasi belok dan kontrol kecepatan secara real-time.

🌐

Koneksi IoT

Menggunakan modul nirkabel hemat daya dengan latensi rendah untuk menjaga kestabilan komunikasi data.

🔋

Driver Motor L298N

Sistem driver motor DC ganda mampu menangani lonjakan arus dan memaksimalkan performa mobil RC.

🔄 Cara Kerja Sistem

Alur kerja dari perangkat keras hingga kendali real-time yang digunakan dalam proyek ini.

1

Input Aplikasi

Pengguna mengirim perintah gerak melalui aplikasi atau tombol kendali di smartphone.

2

Komunikasi Nirkabel

Data dikirim melalui modul Bluetooth/IoT ke Arduino Uno untuk proses decoding sinyal.

3

Pengolahan Kontrol

Arduino memproses sinyal lalu mengatur arah putaran motor melalui driver L298N.

4

Aktuasi Gerak

Roda bergerak sesuai mode maju, mundur, belok kiri, kanan, atau berhenti.
